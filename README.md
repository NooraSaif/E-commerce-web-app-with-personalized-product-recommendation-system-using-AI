# E-commerce Web App with Personalized Product Recommendation System Using AI


A full-stack e-commerce web application featuring an AI-driven relevant, personalized, and real-time product recommendation engine designed to enhance user engagement.

---

## 🚀 Key Features

*   **Personalized Recommendation System:** Uses Content-Based Filtering with TF-IDF and cosine similarity, It uses Cashe memory to deliver real-time product suggestions based on user behavior.
*   **User Dashboard:** Displays personalized product, order history, catalog search, and manage shopping cart.
*   **Admin Control Panl:** mange products, customers and orders.
*   **Online Payment:** Integrating a payment service provider 'Strip'   

## 🛠️ Tech Stack

### Frontend
*   **Language:** HTML / CSS / JS 
*   **Library:** Bootstrap

### Backend & Database
*   **Server:** Python / Flask
*   **Database:** SQLlit / SQLAlchemy

### Machine Learning
*   **Libraries:** Scikit-learn / Numpay / Pandas
*   **Approch:** TF-IDF vector / Cosine Similarity
